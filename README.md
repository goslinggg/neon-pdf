# Neon PDF

Лёгкий просмотрщик PDF для Windows 11 с вкладками и пометками стилусом.

## Возможности

- Открытие локальных PDF, в том числе через «Открыть с помощью» в Проводнике.
- Несколько PDF во вкладках.
- Рисование мышью или графическим планшетом: палитра цветов, толщина линии и мягкое сглаживание штриха.
- Распознавание линии, круга и квадрата после удержания пера две секунды. Линия вращается вокруг начальной точки; круг и квадрат меняют размер, а квадрат может зеркально перейти через нижнюю левую опору.
- Отмена и повтор действия: `Ctrl+Z` / `Ctrl+Y` — также на русской раскладке.
- Масштаб: `Ctrl+Plus`, `Ctrl+Minus`, `Ctrl+0`.
- Сохранение PDF с пометками на компьютер.
- Виртуализация страниц для меньшего потребления памяти на больших PDF.

## Установка

Скачайте установщик из раздела **Releases** и запустите `Neon PDF Setup`.

## Сборка из исходников

```powershell
npm install
npm run dist
```

Готовый установщик появится в папке `release`.
